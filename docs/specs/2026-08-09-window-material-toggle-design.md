# 窗口材质开关设计

## 目标

在设置中增加一个默认开启、可持久化的“窗口玻璃材质”开关。开启时 macOS 使用玻璃材质、Windows 使用 Acrylic，并保留界面内部毛玻璃；关闭时同时移除原生窗口材质并将界面改为不透明。

## 实现

- 前端用 `localStorage` 保存开关值，并在启动及变更时同步根元素的材质状态。
- Tauri 新增一个跨平台命令：macOS 应用或移除 vibrancy，Windows 应用或移除 Acrylic；其他平台安全地不执行材质操作。
- CSS 在材质关闭时覆盖窗口、标题栏、工具栏、侧栏、检查器、菜单、弹窗和玻璃控件的半透明背景及 `backdrop-filter`，画布配置保持独立。
- 设置变化即时生效，无需重启。原生命令失败时保留不透明 CSS 回退并在状态栏显示错误。
- 版本按用户指定更新为 0.5.1。
