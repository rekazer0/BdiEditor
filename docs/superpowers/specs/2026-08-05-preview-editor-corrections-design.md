# 皮肤预览与编辑交互修复设计

日期：2026-08-05

## 目标

修复百度输入法皮肤编辑器中预览渲染、模拟输入、检查器、编辑操作和导出入口的现有问题。预览必须从皮肤文件本身解析颜色、透明度、图片切片、字体和布局，不得按浅色或深色模式硬编码工具栏颜色。

本轮保持现有 Tauri + TypeScript + Canvas/DOM 架构，不新增运行时依赖，不实现真实百度输入引擎。

## 参考与验收样例

主要兼容样例：

`/Users/kaze/Downloads/森林集の薄雾与尘埃/尘埃/苹果/14键/尘埃_适配iOS26-14键无筛选.bdi`

预览以用户提供的 iPhone 17 Pro 真机截图为视觉基准。皮肤中透明的候选栏和工具栏必须透出宿主应用背景；不能用黑色或白色矩形代替透明区域。

## 设计

### 1. 渲染与模拟状态分离

完整皮肤渲染只在皮肤、布局、方向、明暗模式或配置发生变化时运行。键盘点击、文本输入、退格和候选状态变化只更新模拟输入区域及候选内容，不重新创建图集解析器，也不重新解码或重绘所有按键画布。

这样消除输入时整机预览闪烁，同时保持皮肤编辑后的即时重绘。

### 2. 工具栏与候选栏透明度

工具栏和候选栏继续使用皮肤配置中的样式编号解析。颜色按皮肤格式中的 ARGB 顺序解析，透明度为零时不绘制纯色背景；图集切片保持原始 alpha 通道。宿主键盘材质只绘制一次，候选栏和工具栏仅叠加实际存在且非全透明的皮肤层。

修复前先用样例验证以下完整链路：配置样式编号 → 样式节 → 图集/颜色 → alpha → Canvas 合成。浅色与深色使用各自目录中的配置和资源，不交换模式，也不使用主题兜底色覆盖解析结果。

### 3. 背景与前景样式预览

检查器中的 `BACK_STYLE`、`FORE_STYLE` 及按下状态显示解析后的缩略图。缩略图绘制图集的实际源矩形，不直接显示整张图集；复合前景样式按配置顺序合成。

缩略图保留现有 Command 点击跳转功能，跳转到实际资源或样式源文件。无法解析时显示明确的“未找到资源”，而不是空白棋盘格。

### 4. 字体解析

复合前景样式可能把字体名、字号和颜色分散在不同样式节中。解析器分别合并每项属性，而不是遇到第一个样式后提前返回。皮肤中的字体名称原样保存；预览时将 iOS 私有系统字体别名映射到 macOS/WebView 可用的系统字体族，其他可用字体直接使用。

### 5. 模拟输入与候选逻辑

候选栏只把当前光标前连续的拉丁字母和英文撇号识别为拼音组合。空格、标点、换行和功能操作会结束组合，因此标点不会被复制进候选栏。

是否显示中文模拟候选由当前实际布局文件判断，而不是由“9 键/26 键”外层选择推断：

- 中文布局显示拼音和少量模拟中文候选。
- 英文布局只显示英文组合或英文建议，不显示“你好”等中文候选。
- 本功能仍为预览模拟，不执行百度输入法内部词库。

退格删除光标前字符，并保持光标位置；不会强制把光标移到文本开头。

### 6. 编辑模式键盘移动

编辑模式中，选中一个或多个按键后可用方向键移动：普通方向键每次移动 1 个皮肤逻辑单位，Shift + 方向键每次移动 10 个单位。焦点位于输入框、文本区、选择框或可编辑文本时，不拦截方向键。

一次按键移动作为一次可撤销操作。交互预览模式保持只读，不允许移动。

### 7. 页面文字与选择反馈

画布不再把 `KEY1`、`KEY32` 等配置节名称作为按键文字兜底。没有显示文字或前景图片的按键保持空白；编辑模式仅用选择描边和检查器标题表示配置节名称。

### 8. 导出入口

移除标题栏下拉菜单中不可见、难以点击的原生选择框，改成两个明确的菜单按钮：

- 导出 iOS 皮肤（`.bdi`）
- 导出 Android 皮肤（`.bds`）

按钮位于非拖动区域，具备明确文字、悬停和键盘焦点状态。每次点击直接使用对应格式打开保存流程，不依赖另一个隐藏状态。

### 9. 内置默认模板

应用包含一个固定的、经过导入校验的默认模板。新建皮肤会复制该内置模板为未命名文档。

删除“设为默认模板”入口、用户模板路径和相关本地存储逻辑。用户可以编辑、保存或导出由模板创建的文档，但不能替换应用内置模板；打开其他皮肤也不会改变它。

### 10. 错误处理

- 样式节、图集或字体无法解析时，检查器显示具体缺失项，并让其他可解析内容继续显示。
- 新建、打开或退出当前未保存文档时继续使用现有保存确认流程。
- 导出失败显示目标格式和底层错误，不产生看似成功的空文件。

## 测试策略

所有行为修改先增加会失败的自动测试，再进行最小实现：

1. ARGB 透明颜色与透明图集层不会产生黑白矩形。
2. 复合前景样式能合并字体名、字号和颜色。
3. 缩略图使用正确图集切片，并能定位源资源。
4. 中文、英文、标点和退格的模拟候选行为符合规则。
5. 编辑模式方向键移动单选与多选；输入控件不被拦截。
6. 空显示按键不会渲染配置节名称。
7. 新建固定使用内置模板，代码中不存在用户设置默认模板的入口。
8. 导出菜单的两个按钮可聚焦并分别选择 `.bdi`、`.bds`。

完成后运行全部 TypeScript 测试、类型检查、前端生产构建和 Tauri macOS 打包。交付物只提供 `.app`，不额外输出 DMG 或 updater 包。

## 不在本轮范围

- 真实拼音词库、联想学习或百度输入法功能码执行。
- 新的 UI 框架、Canvas 框架或字体依赖。
- 用户自定义默认模板。
- Windows 安装包。
