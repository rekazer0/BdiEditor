# 预览工作区与设备显示修复设计

## 目标

修复编辑器预览中的模糊和尺寸错误，统一设备切换行为，并完善新建项目、图片资源预览和皮肤信息检查器。

本轮保留现有 Tauri、TypeScript、原生 DOM 和 Canvas 架构，不新增运行时依赖，不重构归档格式或编辑器状态模型。

## 已确认根因

1. 符号面板自己的 `[PANEL] SIZE=1125,728` 和 `BACK_STYLE=1104` 被 `gen.ini` 的通用 `1125,595` 覆盖。Canvas 根据内容扩展到约 717 高，但 CSS Grid 仍分配 595 高，产生约 17% 的纵向重采样和模糊。
2. Android 的安全区几何虽然返回零，但地球和麦克风仍是 Grid 中的静态元素，自动最小高度会撑开第三行。横竖屏切换时几何变量也没有全部重算，可能沿用上一个设备的值。
3. 预览缩放使用 CSS `zoom` 缩放整个设备和 Canvas，在非 100% 状态会继续引入重采样。
4. 设备选择器的首项是 iPhone，初始设备壳也硬编码为 iPhone，所以打开应用默认不是画布。
5. 顶部文件按钮本身已左对齐，但标题栏左内边距固定为 76px，导致按钮组整体右移。
6. 图片选择只更新右侧 `#asset`，中央工作区继续由旧的 `layoutDocument` 驱动，因此仍显示上一个键盘。
7. 当前未提交的新建项目实现已有模板弹窗和模板 ID 映射，但仓库仅包含一个真实内置模板。

## 设计

### 1. 清晰且尺寸一致的组件预览

新增一个可测试的面板配置解析边界。当前选中的布局或组件文档存在有效 `[PANEL] SIZE` 或 `BACK_STYLE` 时，分别优先使用组件值；缺失的属性才回退到 `gen.ini` 的通用配置。

同一份最终面板宽、高和背景样式同时传给 `Preview.setPanel()` 与设备几何计算。Canvas 内部尺寸、CSS Grid 行高和命中坐标因此保持一致，不再对符号面板做非等比压缩。

删除预览缩放控件和完整运行时链路，包括 DOM、状态、监听器、CSS `zoom`、`src/zoom.ts` 及其测试。布局检查器中的按键尺寸编辑不受影响。

### 2. 设备与底部附件

设备或方向变化时始终重算并覆盖候选栏、面板和安全区的全部 CSS 变量，不允许沿用上一设备状态。

地球和麦克风只在 iPhone 竖屏设备预览中显示并参与布局；Android、横屏和纯画布模式明确隐藏附件，且不为附件保留 Grid 行高。Android 的设备框、状态栏和打孔屏样式保持现状。

设备选择器默认选中 `canvas`，显示文字为“画布”。初始设备壳同时带有纯画布状态，避免脚本初始化前短暂显示 iPhone 外框。

### 3. 顶部文件操作

标题栏采用常规 12px 左右内边距，使新建、打开、保存、撤销和重做按钮组贴近窗口左侧。按钮仍保持图标形式、现有工具提示、拖动区域和可访问名称。

现有未提交的“新建项目”改动作为本轮基础保留。弹窗由模板注册表生成或校验选择项，选择后才执行未保存文档确认并加载模板；取消不会替换当前项目。

仓库当前只有 `public/default-template.bdi` 一个有效模板，因此本轮只展示这个真实选项。结构允许后续增加新的模板 ID 和资源，但本轮不复制或伪造第二个模板。

### 4. 图片资源预览

在中央 `.canvas-wrap` 中增加与设备壳同级的图片查看器。选择归档内 PNG 时隐藏设备壳并显示中央图片；选择文本或布局时恢复设备预览。切换视图不清除最近的布局文档，返回布局不需要重新推断状态。

中央查看器和右侧检查器复用同一个 Blob URL。切换图片、加载新归档或释放当前归档时撤销旧 URL。图片加载失败时显示明确错误状态，不能留下旧图或空白区域。

右侧图片预览继续归属于“属性”视图：图片选中时启用并激活属性页、禁用源代码页，显示路径、预览和现有替换按钮。交互预览模式允许查看，只有编辑模式允许替换。

本轮继续仅支持 PNG，与现有 `SkinArchive.isImage()`、图集解析和替换输入一致；不开放本地文件协议或 SVG。

### 5. 皮肤信息兼容

从 Info 检查器删除 `data-skin-field="Authors"` 的“共同作者”输入框。此变更只影响可编辑 UI，不删除或重写归档里的 `Authors=` 行；编辑其他 Info 字段和导出时仍保留原始共同作者元数据。

## 错误处理

- 模板 ID 未知、模板资源加载失败或响应无效时，继续使用现有文件操作错误通道，不替换当前项目。
- 图片无法解码时中央与右侧显示失败状态，旧 Blob URL 被撤销。
- 组件 `[PANEL] SIZE` 无效时逐项回退到通用配置，不向 Canvas 传递非有限值或非正尺寸。
- 设备切换没有对应 `DeviceSpec` 时按纯画布处理，并清除设备专属几何变量。

## 测试策略

所有行为修改遵循测试先行：

1. 面板配置测试证明符号面板得到 `1125x728` 和 `1104`，缺失字段才回退通用配置。
2. 设备几何测试覆盖 iPhone 竖屏、Android 竖屏、横屏和连续切换，证明附件只在 iPhone 竖屏存在且无残留安全区。
3. UI 结构测试证明默认选项和文案为“画布”、缩放链路完全移除、标题栏使用 12px 左内边距。
4. 图片工作区测试覆盖文本到图片再回文本、中央与右侧共享预览、旧 URL 回收、损坏 PNG 和替换后的同步刷新。
5. 新建项目测试覆盖选择、取消、未知模板和加载失败；模板档案本身继续通过现有归档校验。
6. Info 测试证明检查器不再暴露共同作者输入框，同时 `IniDocument` 修改其他字段后仍保留 `Authors=`。

完成后运行全部 Node 测试、`npx tsc --noEmit`、Vite 生产构建，并使用本地应用截图检查画布、iPhone、Xiaomi 和符号面板在桌面视口中的实际像素清晰度与布局。

## 不在本轮范围

- 新增或生成第二个默认模板。
- 支持 PNG 以外的资源图片格式。
- 重写整个预览状态模型或引入 UI 框架。
- 修改皮肤归档中的作者归属数据。
- 修改按键尺寸、对齐、拖动等布局编辑能力。
