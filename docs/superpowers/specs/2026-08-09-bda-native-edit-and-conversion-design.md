# BDA 原生编辑与 BDI/BDS 转换设计

## 目标

保留 BDA 原生编辑和 BDA 导出，并允许将已导入的 BDA 有损导出为 BDS 或 BDI。界面只显示 BDA 包内实际存在的配置；BDA 专属的序列帧、按键背景动画、声音和开关配置由 protobuf 解析后显示和编辑。

## 架构

`SkinArchive` 继续保存原始 BDA 文件和未知 protobuf 字段。BDA 编辑直接补丁对应配置，BDA 导出沿用现有原包回存逻辑。

BDS/BDI 导出时才生成转换模型：复制现有 `public/bda-base.bds` 的官方基础布局，叠加 BDA 的资源、外观和可映射配置，然后交给现有 BDS/BDI `packagedBytes` 链路打包。不维护第二份长期项目状态，也不引入新依赖。

## 界面与数据流

1. 导入 BDA 后索引包内实际配置文件。
2. 文件树和检查器只注册实际存在且已解析的 BDA 配置；基础布局仅供内部预览和转换，不作为 BDA 自带文件显示。
3. 外观、动画、声音和开关编辑直接修改对应 protobuf，同时保留未识别字段。
4. 导出 BDA 时写回原始归档。
5. 导出 BDS/BDI 时临时构建转换归档，并复用已有 BDS/BDI 打包器。

## 转换规则

- BDA 图片、字体、颜色和可对应的按键样式映射到基础布局中的同类字段。
- BDA 资源按原文件名复制到转换归档，已有资源 ID 映射继续复用。
- BDS/BDI 没有等价表达的序列帧动画使用首个有效帧作为静态图。
- 按键按下动画优先取按下序列首帧；没有按下序列时回退到普通首帧。
- 声音、开关及其他无法表示的 BDA 专属配置不写入 BDS/BDI，并在导出前显示一次降级提示。
- 转换失败不修改原始 BDA，也不生成残缺文件。

## 错误处理

- 缺少可选配置时隐藏相应界面，不报错。
- protobuf 损坏或缺少基础布局时阻止对应预览或转换，并指出具体配置路径。
- 找不到动画帧时保留普通静态样式；普通样式也不存在时保持基础布局默认值。
- 未识别 protobuf 字段按原字节保留，避免 BDA 回存丢失未来格式内容。

## 验证

- 使用提供的 BDA 样本验证实际配置过滤、外观解析和动画首帧降级。
- 添加最小测试，确认 BDA 仍能回存、同一 BDA 能导出 BDS/BDI、转换归档可重新打开。
- 运行现有测试和生产构建；修改成功后才按补丁版本规则更新版本号。

## 非目标

- 不在 BDS/BDI 中模拟其格式本身不支持的动画运行时。
- 不猜测或显示 BDA 包内不存在的配置。
- 不创建新的通用转换框架或插件系统。
