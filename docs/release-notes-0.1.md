# BDI 皮肤编辑器 0.1

首个 macOS 版本，面向百度输入法 iOS `.bdi` 与 Android `.bds` 皮肤。

## 主要功能

- 九键、魔改九键和 26 键语义化导航；
- 浅色/深色、横屏/竖屏实时画布；
- iPhone 17 Pro、iPhone 17 Pro Max、Xiaomi 17、Pixel 10 Pro 与 Galaxy S25 Ultra 的厂商分辨率模板和整机横竖屏；
- 与参考设备一致的底部全宽键盘和系统附件区，移除手机预览内多余的候选模拟条与格式工具条；
- 深色皮肤会同步切换手机屏幕、导航、输入区和键盘底板；
- 普通与按下外观、上下左右滑动和长按事件预览；
- Command/Ctrl/Shift 多选、方向键移动、对齐、等尺寸、分布与精确间距；
- 候选栏、符号面板、工具栏可视化和字面按键模拟输入；
- 显示文字与实际输入分离编辑；
- 背景/前景真实图集切片预览，以及字体、字重、字号和 AARRGGBB 颜色编辑；
- 整体键盘高度与背景编辑、皮肤信息解析、多选按键图片批量编辑；
- 上滑等手势可模拟切换符号、数字、ABC 和显式 `Z+` 页面；
- 配置文本与画布双向同步、撤销/重做；
- 配置源码提供无额外依赖的 INI 语法高亮；
- PNG 资源预览与替换；
- 固定内置默认模板、新建、保存与未保存保护；用户不能替换内置模板；
- iOS BDI 与 Android BDS 直接独立导出，除扩展名外还会转换平台目录结构、`SupportPlatform` 和 Android `Style`；
- `.bdi/.bds` Finder 文件关联；
- 保留未知字段、注释、顺序和未修改资源。
- 保留原始 ZIP 条目顺序、权限、时间扩展字段和未修改压缩记录；
- 红色关闭按钮会在未保存确认后完整退出应用。
- 文件操作防止重复点击，并检查模板失效、损坏皮肤、读取失败和写入失败；错误同时显示在状态栏与原生对话框。

## 验证

- 87 个前端自动测试和 1 个 Rust 文件命令测试全部通过；
- 3 份真实 iOS/Android、双主题样本完成布局、动作、样式与 PNG 往返；
- 最终 `.app` 通过严格代码签名校验，内置模板与源文件 SHA-256 一致。

## 边界

0.1 只还原键盘外观与按键状态，不实现真实拼音词库、真实输入引擎或百度内部 `Fxx/Sxx` 功能。候选词、符号、数字、ABC 和显式 `Z+` 页面切换是编辑器预览模拟。当前仅发布 Apple Silicon macOS `.app`；Windows 使用同一业务代码，待后续构建验证。

应用使用 ad-hoc 签名，尚未使用 Apple Developer ID 公证。首次打开若被 Gatekeeper 拦截，请在 Finder 中右键应用并选择“打开”。
